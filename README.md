# ICML 2026 — SOSMC

Independent clean-room evidence audit for **Efficient Stochastic Optimisation
via Sequential Monte Carlo** by James Cuin, Davide Carbone, Yanbo Tang, and
O. Deniz Akyildiz.

## Result

**Overall status: INCONCLUSIVE**

- 5/5 bounded finite or special-case diagnostics pass.
- 0/6 paper-level claims are independently verified.
- C6 is an explicit negative because the required MNIST EBM campaign is
  absent.

This repository is the normalized copy of
icml26-repro-hCIBCAS1Hi-sosmc. The canonical repository is
[icml26-sosmc-sequential-monte-carlo](https://github.com/MachineLearning-Nerd/icml26-sosmc-sequential-monte-carlo).

## Paper

The paper studies optimization problems whose gradients are expectations over
parameter-dependent, intractable distributions. SOSMC treats the sequence of
optimization targets as an SMC path, reuses particles, updates incremental
weights, and resamples when the effective sample size is low. The paper
analyzes idealized convergence and ESS behavior and evaluates reward tuning
for Langevin processes and energy-based models, including MNIST.

- Authors: James Cuin, Davide Carbone, Yanbo Tang, and O. Deniz Akyildiz
- Audit source pin: arXiv 2601.22003v1
- Latest paper record: [arXiv 2601.22003v2](https://arxiv.org/abs/2601.22003)
- HTML paper: https://arxiv.org/html/2601.22003
- OpenReview record: https://openreview.net/forum?id=hCIBCAS1Hi
- Official author code: https://github.com/akyildiz-group/SOSMC

This repository is an independent audit. It does not copy or claim to be the
official author implementation.

## What this repository contains

- repro/src/verify.py runs a deterministic-seed CPU audit on one
  closed-form Gaussian/quadratic instance and one numerical quartic grid.
- repro/tests/test_sosmc.py contains four independent identity and rate
  checks.
- outputs/verdict.json is the canonical six-claim evidence record.
- outputs/gate.json and publication_gate.json are generated by
  repro/src/finalize_gate.py.
- outputs/verify_run.log records the latest bounded verifier result.
- .trackio/logbook contains the synchronized experiment notes.

The implementation does not provide the paper's general SMC propagation and
resampling campaign, EBM training, ImpDiff comparison, 2D EBM benchmarks, or
MNIST kernel-mismatch experiment.

## Claim-to-evidence ledger

| Claim | Paper statement | Evidence produced here | Status |
| --- | --- | --- | --- |
| C1 | Algorithm 1 and Lemma 1: weighted particle gradients are consistent. | Direct Monte Carlo score-identity estimates from one known Gaussian at five sample sizes. | FINITE_CONSISTENCY_PROXY |
| C2 | Proposition 2: the idealized update has the PL/smooth linear rate. | Exact gradient descent on a selected anisotropic quadratic, plus divergence and non-PL negative controls. | CONDITIONAL_EXACT_CERTIFICATE |
| C3 | Equation 19 and Propositions 3–4: ESS has the Gaussian identity and general small-step behavior. | Exact equal-covariance Gaussian calculation, empirical ESS, and a numerical one-dimensional quartic grid. | CONDITIONAL_EXACT_CERTIFICATE |
| C4 | Section 5: SOSMC reduces variance and improves relevant baselines. | Finite MSE slope and a hand-built single-chain ULA comparison on the synthetic instance. | FINITE_VARIANCE_REDUCTION_PROXY |
| C5 | Particle estimates track the true gradient during optimization. | Twelve-step Gaussian/quadratic particle-gradient trajectory with finite tracking and convergence checks. | FINITE_TRACKING_PROXY |
| C6 | Section 5.3: MNIST robustness under kernel mismatch. | No MNIST EBM run is present; the missing experiment is recorded as an honest negative. | NOT_REPRODUCED |

Each claim includes paper_statement, finite_proxy_passed,
paper_claim_verified, limitations, and production_path fields in
outputs/verdict.json. The production path for the five diagnostics is:

~~~text
repro/src/verify.py
        |
        v
outputs/verdict.json
        |
        v
repro/src/finalize_gate.py
        |
        +--> outputs/gate.json
        +--> publication_gate.json
~~~

## How to reproduce the audit

Install NumPy, then run:

~~~bash
python3 repro/src/verify.py
python3 repro/tests/test_sosmc.py
python3 repro/src/finalize_gate.py
python3 -m json.tool outputs/verdict.json
python3 -m json.tool outputs/gate.json
~~~

The verifier uses a fixed random seed. The unit file includes a 2-million
sample Monte Carlo check and is intentionally separate from the publication
gate. A passing gate means the evidence labels are internally consistent; it
does not convert special-case calculations into general theorem verification.
